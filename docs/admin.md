# admin.html (private panel, `noindex`)

- Login: Supabase `/auth/v1/token?grant_type=password`; JWT in `sessionStorage['ezt']`. All data via `api()` -> `/rest/v1/...` with anon key + bearer. 401 / `PGRST303` signs out. `ERR` maps Postgres exception names (`slot_taken`, `not_admin`...) to text. User text into `innerHTML` must go through `esc()`.
- **Bookings tabs**: Pending / Confirmed / Declined-cancelled (by `status`). RPCs taking `p_id`: `approve_booking`, `decline_booking`, `cancel_booking`, `delete_booking`. Restore dropdown on cancelled/declined -> `admin_restore_booking(p_id,p_to,p_date)`: to Confirmed (any free date; removes the "Cancelled booking (...)" day off) or New requests (only without a paid deposit). "Text it" opens the phone's SMS app prefilled (no Twilio/10DLC).
- **Deposit link**: "Approve and create deposit link" -> `admin_send_deposit_link`, then `mailLink()` emails it via Edge Function `send-deposit-link` (Resend, BCC owner), falling back to FormSubmit `_autoresponse` (unreliable). "Email the link" checkbox: on for new approvals, off when updating an existing hold (owner doesn't want customers re-emailed).
- **Days off**: calendar + range form. `admin_list_blocked_days`, `block_days(p_from,p_to,p_note)`, `unblock_day(p_day)`.
- **Reviews**: Waiting / Live / Hidden (`pending`/`approved`/`rejected`) via `admin_list_reviews(p_status)`; `set_review_status(p_id,p_status)`, `delete_review(p_id)`. Tab label = waiting count.
- **Gallery**: photo upload resized in-browser to webp 2000px + 900px thumb; video re-encoded in-browser to H.264 MP4 ≤1280px (canvas + `MediaRecorder` + WebAudio, real-time; `fixDur()` patches duration; needs a picture or grabbed frame as `thumb`). Files -> Storage `gallery/` with admin JWT, then `admin_add_gallery_item`; list reorders (`admin_move_gallery_item`), edits/takes down (`admin_update_gallery_item`), deletes (`admin_delete_gallery_item` returns Storage paths to erase). Repo-hosted seed items have empty `paths`.
  - Upload "Spot": First / Numeric order / Last. **Numeric order** (owner's rule, `gCmp`): star count ascending (number in name, else small line; none = last), then brandless names (`gGen`: Truck, Sedan, SUV...) first, then vehicle A-Z. Inserts by adding first then moving down. Keep fallback `GALLERY` arrays in index/gallery.html in this order.
- **Materials**: master parts list across confirmed jobs, grouped by item name (case-insensitive, numeric sort), e.g. "650 starlight kit x2". `admin_list_materials()`; tick group or single job -> `admin_set_materials_ordered(p_ids,p_ordered)`; `admin_add_material(p_item,p_qty,p_booking)`, `admin_delete_material(p_id)`. Tab label = items still to order. Item mapping is SQL `materials_for()` (see [backend.md](backend.md)).
- Light mode washes the photo background so headings stay readable.
